Tools currently listed in Agent Frameworks — Building AI Agents

  • LangGraph — Low-level framework from the LangChain team for stateful, long-running agents — graphs of nodes and edges with durable execution and human-in-the-loop.
  • CrewAI — Python framework for teams of role-based AI agents (Crews) plus event-driven Flows for production control — MCP and A2A built in.
  • Microsoft Agent Framework — Microsoft's open-source framework for production agents and multi-agent workflows in .NET and Python — the direct successor to AutoGen and Semantic Kernel
  • OpenAI Agents SDK — OpenAI's lightweight, provider-agnostic agent SDK for Python and TypeScript — handoffs, guardrails, sessions and tracing built in.
  • Google ADK — Google's open-source, code-first Agent Development Kit for Python, TypeScript, Go, Java and Kotlin — graph workflows, A2A and MCP.
  • LlamaIndex — Open-source Python framework for agents and RAG over your own data — connectors, indexes, query engines and agent workflows.
  • AgentScope — Open-source Python agent framework with a ready-made agent service — ReAct agents, agent teams, MCP and A2A, sandboxed tools
  • Browser-Use — Open-source Python library that lets AI agents use a web browser with any LLM — plus Browser Use Cloud for hosted browsers and agents.
  • Pydantic AI — Type-safe Python agent framework from the Pydantic team — validated structured output, many model providers, evals, durable execution and MCP.
  • Mastra — TypeScript framework for AI agents and apps from the team behind Gatsby — agents, graph workflows, memory, RAG, evals, MCP and A2A.
