Đã rút khỏi danh sách trong đợt rà soát card tháng 10/2026: mục Agent Frameworks nay tập trung vào các framework LLM agent đa dụng. Rasa vẫn là nền tảng AI hội thoại đang hoạt động.

Xem các công cụ hiện có trong Agent Frameworks — Xây dựng AI agents.

Công cụ đang có trong Agent Frameworks — Xây dựng AI agents

  • LangGraph — Framework cấp thấp của đội LangChain cho agent có trạng thái, chạy dài — đồ thị node và edge, có durable execution và human-in-the-loop.
  • CrewAI — Framework Python cho đội AI agent theo vai trò (Crews) cùng Flows điều khiển theo sự kiện cho production — MCP và A2A tích hợp sẵn.
  • Microsoft Agent Framework — Framework mã nguồn mở của Microsoft cho agent production và workflow nhiều agent trên .NET và Python — bản kế nhiệm trực tiếp của AutoGen và Semantic Kernel
  • OpenAI Agents SDK — SDK agent gọn nhẹ của OpenAI cho Python và TypeScript, không phụ thuộc provider — handoffs, guardrails, sessions và tracing có sẵn.
  • Google ADK — Agent Development Kit mã nguồn mở, code-first của Google cho Python, TypeScript, Go, Java và Kotlin — graph workflows, A2A và MCP.
  • LlamaIndex — Framework Python mã nguồn mở cho agent và RAG trên dữ liệu riêng — connectors, indexes, query engines và agent workflows.
  • AgentScope — Framework agent Python mã nguồn mở kèm sẵn agent service — ReAct agent, agent team, MCP và A2A, tool chạy trong sandbox
  • Browser-Use — Thư viện Python mã nguồn mở cho AI agent dùng trình duyệt web với mọi LLM — kèm Browser Use Cloud cho trình duyệt và agent hosted.
  • Pydantic AI — Framework agent Python type-safe của đội Pydantic — output có cấu trúc được kiểm tra, nhiều model provider, evals, durable execution và MCP.
  • Mastra — Framework TypeScript cho AI agent và ứng dụng từ đội làm Gatsby — agents, graph workflows, memory, RAG, evals, MCP và A2A.
